# network-security-lab
Practical network and IT security lab using Kali Linux, Metasploitable, Nmap and Wireshark.

# Network Security Lab

## Ziel
Praktische Untersuchung eines virtuellen Netzwerks
und Analyse von Netzwerkdiensten.

## Umgebung
- Kali Linux
- Metasploitable 2
- VirtualBox
- Nmap
- Wireshark

## Durchgeführte Aufgaben
- Netzwerk zwischen virtuellen Maschinen eingerichtet
- Host mit Nmap untersucht
- Offene Ports identifiziert
- Laufende Netzwerkdienste analysiert
- Netzwerkverkehr mit Wireshark untersucht

## Erkenntnisse
- Unterschied zwischen offenen und geschlossenen Ports
- Zusammenhang zwischen Ports und Netzwerkdiensten
- Grundlagen der TCP/IP-Kommunikation
- Bedeutung der Netzwerküberwachung
